
# Calix Vesper

부산외대 Canvas 일정 관리 앱. iOS 17 이상.

## Aurora 연동

1. 두 기기를 같은 Wi-Fi에 연결합니다.
2. Aurora의 **설정 → 기기 연동 → QR 생성**을 누릅니다.
3. Vesper의 **더 보기 → Aurora 연동**에서 QR을 스캔하고 연동을 요청합니다.
4. 두 화면의 확인 코드가 같으면 Aurora에서 승인합니다.

개인 일정, 체크리스트, 시간표, 직접 입력한 학점, 일반 일기, 집중 기록, 휴일을 양방향으로 동기화합니다. 같은 학교 계정의 과제와 영상 제목·메모도 동기화합니다. 출결과 학교 제출 상태는 조회용으로 가져옵니다. 양쪽에서 같은 항목을 수정하면 각 기기의 변경을 유지합니다.

닉네임도 연동합니다. 학과와 학번은 Vesper 기기에 저장합니다. 학교 로그인, PIN, 비밀 일기와 일반 일기 서식은 기기별로 관리합니다.

시간표 오른쪽 위 팔레트에서 학기별 테마를 선택합니다. Aurora에서 연동한 테마와 프리셋도 선택할 수 있습니다.

## 실행

`Calix.xcodeproj`의 `Calix` 스킴을 실행합니다. GitHub Actions는 iPhone 13 시뮬레이터에서 연동을 검사하고 10개 화면을 캡처합니다.
